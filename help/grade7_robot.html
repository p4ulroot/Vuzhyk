5.1. Исполнитель Робот

Робот — автоматическое устройство, которое действует по заранее составленной программе. Робот получает сведения о мире от датчиков.

В учебнике используется учебный компьютерный исполнитель Робот (библиотека pyrob). В отличие от Черепахи, Робот не входит в стандартную библиотеку Python.

Среда обитания — прямоугольное клетчатое поле. Между клетками и по периметру могут быть стены. Робот ходит по клеткам и закрашивает их. Поле с стенами, начальной и конечной клетками и пометками закраски называют обстановкой.

В Vuzhyk задания Робота можно открывать в редакторе Pyrob. Подключение исполнителя:

from pyrob.api import *

Готовые задания вызывают декоратором @task. Имя функции должно совпадать с именем задачи: примеры учебника начинаются с prim, упражнения — с upr.

from pyrob.api import *

@task
def prim_12_1():
    move_right(4)
    move_up()
    move_left(2)
    fill_cell()
    move_left()
    fill_cell()
    move_left(2)

run_tasks()

Система команд

КомандаДействие
move_right()вправо
move_left()влево
move_up()вверх
move_down()вниз
fill_cell()закрасить текущую клетку

У команд перемещения может быть параметр — сколько клеток пройти. Без параметра Робот сдвигается на одну клетку. Команды можно выбирать из списка: первые буквы и Ctrl + пробел.

Робот не проходит сквозь стену и не выходит за край поля. Закрасить уже закрашенную клетку можно — это не ошибка. Если задача решена верно, Робот отмечается как успешный; если врезался в стену или закрасил не те клетки — решение считается неверным.

В одной строке можно записать несколько команд через запятую:

from pyrob.api import *

@task
def prim_12_8():
    fill_cell(), move_right()
    fill_cell(), move_right()
    fill_cell(), move_down()
    fill_cell(), move_down()
    fill_cell(), move_left()
    fill_cell(), move_left()
    fill_cell(), move_up()
    fill_cell(), move_up()

run_tasks()

Эта программа закрашивает все клетки поля 3×3, кроме средней, обходя поле по часовой стрелке.
