5.4. Вывод и типы данных

Язык программирования задаёт правила записи программы и действия исполнителя. Python — один из самых используемых языков. В учебном курсе используют среду IDLE; в Vuzhyk программы пишут и запускают в этом же редакторе.

Команда print

print() выводит данные. Аргументы — выводимые значения. Текст заключают в одинарные или двойные кавычки.

print('Привет, мир!')

Необязательные аргументы:

  • sep — разделитель между значениями одной команды (по умолчанию пробел);
  • end — текст после вывода (по умолчанию перевод строки '\n').
print('Привет!', 'Я компьютер!!!')
print('Я умею выполнять', end=' ')
print('программы!', 'Здесь', sep='\n', end=' ')
print('ты', 'написал свою', end=' ')
print('первую программу,', end=' ')
print('и я её выполнил.')
print('Сейчас на экране', end=' - ')
print('её результат.')
print()
print('Ура!', 'Ура!', 'Ура!', sep='!')

Текст в кавычках не вычисляется. Без кавычек выражение сначала считается, затем выводится результат:

print('2 + 2 * 2 =')
print(2 + 2 * 2)
print('2 + 2 * 2 =', 2 + 2 * 2)

Результат второй и третьей форм: 2 + 2 * 2 = 6 (умножение выполняется раньше сложения).

Тип данных и переменная

Данные — информация в формализованном виде, пригодная для обработки на компьютере.

Переменная — именованная ячейка памяти, хранящая значение.

Тип данных определяет способ хранения, диапазон значений и допустимые операции.

Имя переменной: латинские буквы, цифры, знак _. Заглавные и строчные буквы различаются. Целая часть дробного числа отделяется точкой.

a = 2
b_1 = 7.5
radius = 12.0
print(a, b_1, radius)

Переменная a — целая, b_1 и radius — рациональные.

Присваивание и операции

x = 9
x1 = 3.5
a_1 = 20 * (x + x1) - 32
y = 3
chastnoe = x / y
y = 7 + 2 * y ** 3
print('x =', x)
print('x1 =', x1)
print('a_1 =', a_1)
print('chastnoe =', chastnoe)
print('y =', y)

Знак умножения опускать нельзя. Приоритет как в математике: степень, затем умножение и деление, затем сложение и вычитание. Порядок меняют скобками.

Изменение значения в той же ячейке:

a = a * 2   # или a *= 2
b = b - 3   # или b -= 3

Вычисления с целыми числами точные; с рациональными результат может быть приблизительным. Если в выражении есть и целые, и рациональные, результат рациональный.
