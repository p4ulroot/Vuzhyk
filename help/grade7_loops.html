5.2. Циклы

Алгоритмическая конструкция повторение (цикл) задаёт последовательность действий, выполняемых многократно. Эту последовательность называют телом цикла.

Цикл с параметром (for)

Количество повторов известно заранее и зависит от начального и конечного значений параметра (счётчика).

В Python:

for i in range(N1, N2):
    команды

Заголовок читают так: «Для переменной i в диапазоне от N1 до N2 делай…». Значение N2 в range не входит в диапазон.

ЗаписьЗначения i
for i in range(N):0, 1, …, N−1 (N раз)
for i in range(N1, N2):N1, N1+1, …, N2−1
for i in range(N1, N2, h):от N1 с шагом h, пока i < N2
for i in range(5, 0, -1):
    print(i)
for i in range(-20, 30, 10):
    print(i)
for i in range(1, 100, 2):
    print(i)

Вложенные циклы: внутренний выполняется полностью на каждом шаге внешнего.

from pyrob.api import *

@task
def prim_13():
    for i in range(10):
        fill_cell()
        move_right()

run_tasks()

Цикл с предусловием (while)

Тело повторяется, пока условие истинно. Число повторов заранее может быть неизвестно (например, «пока справа нет стены»).

while условие:
    команды

Заголовок читают: «Пока верно условие, делай…».

from pyrob.api import *

@task
def prim_while():
    while not wall_right():
        fill_cell()
        move_right()
    fill_cell()

run_tasks()

Для Робота часто используют проверки стен: wall_right(), wall_left(), wall_up(), wall_down() и отрицание not.
