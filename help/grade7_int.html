5.6. Целые числа: // и %

Для целых чисел в Python есть операции целочисленного деления // и остатка %. Их приоритет такой же, как у умножения и деления.

С версии Python 3.6 в записи числа можно ставить подчёркивания: a = 1_000_000 то же, что a = 1000000.

Знак результата

Знак a // b определяется как в математике: плюс, если числа одного знака, минус — если разного. Результат округляется до ближайшего целого вниз (к меньшему).

Остаток может быть отрицательным. Если он не ноль, знак a % b совпадает со знаком делителя. Связь операций:

a % b = a - (a // b) * b

Частное и остаток

Даны целые a и b. Найти целую часть от деления и остаток.

a = int(input('a = '))
b = int(input('b = '))
c = a // b
d = a % b
print('целая часть =', c)
print('остаток =', d)

Проверка: a = 11, b = 4 → целая часть 2, остаток 3.

Минуты и секунды

Таймер показывает только секунды. Перевести в минуты и секунды: минуты — c // 60, оставшиеся секунды — c % 60.

c = int(input('c = '))
m = c // 60
s = c % 60
print(m, s, sep=':')

Если ввести 125, программа выведет 2:5 (2 минуты и 5 секунд).
