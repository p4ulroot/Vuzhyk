5.3. Ветвление и условия

Алгоритмическая конструкция ветвление выполняет одну или другую последовательность команд в зависимости от истинности условия.

Выполнение начинается с проверки условия. Если оно истинно — выполняется первая ветка, если ложно — вторая. Выполняется только одна из двух последовательностей.

Полная форма

if условие:
    команды_1
else:
    команды_2

После if условие и после else ставят двоеточие. Команды веток пишут со сдвигом.

Сокращённая форма

Если при ложном условии ничего делать не нужно, ветку else опускают:

if условие:
    команды_1

Пример: если на улице дождь — взять зонт; выйти на улицу нужно в любом случае (эта команда стоит после ветвления).

Несколько условий (elif)

Вложенные проверки при ложности предыдущего условия записывают через elif (это «else if»):

if условие1:
    команды_1
elif условие2:
    команды_2
else:
    команды_3

Блоков elif может быть несколько.

Составные условия

Условие может включать несколько проверок, соединённых логическими операциями: and (и), or (или), not (не).

if wall_right() and not wall_down():
    move_down()
elif not wall_right():
    move_right()
else:
    fill_cell()

Для Робота условие — любой понятный ему вопрос о клетке или стенах, на который можно ответить «да» или «нет».
