5.5. Ввод данных и вычисления

input() вводит данные с клавиатуры. Без преобразования всё введённое считается текстом, даже если набраны цифры.

В скобках можно указать подсказку. Чтобы получить число, результат input преобразуют:

x = int(input('целое'))
y = float(input('рациональное'))

Этапы решения задачи

  1. Определение исходных данных.
  2. Определение результатов.
  3. Составление алгоритма.
  4. Определение типов данных для переменных.
  5. Написание программы.
  6. Тестирование программы (проверка на разных наборах данных).
  7. Анализ результатов (вручную, на калькуляторе или другой программой).

Значение выражения

Даны x, y, z. Вычислить a = (2x + y − z) / (3 + x²). Все переменные — тип float.

x = float(input('x = '))
y = float(input('y = '))
z = float(input('z = '))
a = (2 * x + y - z) / (3 + x * x)
print('a =', a)

Проверка: при x = 2, y = 3.1, z = 4 должно получиться примерно 0.4428571428571428.

Частые ошибки в выражениях: пропущен знак * (нельзя писать 2x), непарные скобки.

Геометрическая задача

Дан квадрат со стороной a. Найти площадь и периметр: S = a², P = 4a.

a = float(input('a = '))
S = a * a
P = 4 * a
print('S =', S)
print('P =', P)
