4.1. Подключение модуля с командами управления исполнителем Черепаха

Вариант 1

import turtle — подключить окно без координатной сетки

import turtlexy — подключить окно с координатной сеткой

Каждая команда управления Черепахой записывается после ключевого слова turtle и отделяется от него точкой.

import turtlexy
turtle.shape('turtle')
turtle.left(90)
turtle.forward(100)
turtle.left(90)

Вариант 2

from turtle import * — подключить окно без координатной сетки

from turtlexy import * — подключить окно с координатной сеткой

Команды записываются без ключевого слова turtle.

from turtlexy import *
shape('turtle')
left(90)
forward(100)
left(90)
