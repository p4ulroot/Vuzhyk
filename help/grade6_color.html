4.6. Управление цветом пера исполнителя Черепаха

Варианты задать цвет пера:

  • с помощью английских названий цветов, которые записываются в кавычках, например, 'red', 'yellow';
  • с помощью шестнадцатеричного кода, который записывается в кавычках, например, '#RRGGBB';
  • через RGB-коды (числа от 0 до 1 или от 0 до 255): Red — количество красного цвета, Green — количество зелёного цвета, Blue — количество синего цвета. Три цвета смешивают на экранах, чтобы получить любой другой оттенок, например, чистый красный цвет: rgb(255, 0, 0).

colormode(255) — установить режим ввода цвета через RGB-коды.

colormode(1.0) — отменить режим ввода цвета через RGB-коды.

pencolor(color) — установить цвет линии для пера color.

fillcolor(color) — установить цвет заливки нарисованной фигуры color.

color(color1, color2) — установить цвет линии для пера color1 и цвет заливки нарисованной фигуры color2.

begin_fill() — подготовить к заливке цветом, команда записывается перед началом рисования фигуры.

end_fill() — залить цветом фигуру, нарисованную после последнего вызова begin_fill().

from turtlexy import *
# установить режим ввода цвета через RGB-коды.
colormode(255)
# установить цвет линии и заливки
color((10, 100, 13), (15, 255, 120))
# подготовить к заливке
begin_fill()
# нарисовать круг
circle(100)
# залить цветом фигуру
end_fill()
# отменить режим ввода цвета через RGB-коды.
colormode(1.0)
# установить цвет линии
pencolor('red')
forward(100)
