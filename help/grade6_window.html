4.3. Управление окном исполнителя Черепаха

setup(w, h) — задать размеры окна Черепахи: w — ширина окна, h — высота окна.

from turtlexy import *
setup(700, 631)

title(t) — установить заголовок окна Черепахи: t — строка, которая показана в заголовке графического окна черепахи.

from turtlexy import *
title('Черепаха')

Окно с заголовком «Черепаха»

done() — оставить открытым окно модуля turtle.

clear() — удалить все линии и рисунки с окна, не передвигая саму Черепашку, не меняя её место или цвет.

По окончании выполнения скрипта со сценарием turtle окно сразу закрывается. При выполнении done() окно остаётся открытым. По окончании выполнения скрипта со сценарием turtlexy окно не закрывается, использование done() не требуется.

exitonclick() — закрыть окно модуля turtle по щелчку мышкой.

При выполнении exitonclick() ожидается щелчок мыши по окну, чтобы его закрыть.

hide_grid() — скрыть координатную сетку с осями модуля turtlexy.

show_grid() — показать координатную сетку с осями модуля turtlexy.

show_mouse_coords() — показать подсказку с координатами курсора мыши при использовании turtlexy.

hide_mouse_coords() — скрыть подсказку с координатами курсора при использовании turtlexy.
