4.8. Вспомогательный алгоритм

Вспомогательный алгоритм в языке Python записывается в виде функции:

def имя_функции():
    команда1
    команда2
from turtle import *
# функция для рисования треугольника
def treug():
    forward(100)
    left(120)
    forward(100)
    left(120)
    forward(100)
    left(120)
# нижний треугольник
penup()
setpos(-50, -85)
pendown()
treug()
# средний треугольник
penup()
setpos(-50, 0)
pendown()
treug()
# верхний треугольник
penup()
setpos(-50, 85)
pendown()
treug()
