# Vuzhyk

#EN
Development is currently paused for 1.5 years, so version 26.4.1 will be the final release until the second quarter of 2028.
With the resumption of development, Vuzhyk will transition from Qt5 to its own custom GUI library. This will significantly improve the application's appearance while maintaining the same level of performance on older PCs; on newer but low-end hardware, performance may even see an increase.
At that time, this README will also be properly formatted, and the "Relya" GUI library will be introduced.
A separate version of the IDE—not aimed at schools—will be released, featuring a significantly improved agent and support for a wider range of programming languages.

#RU
Разработка в настоящее время приостановлена ​​на 1,5 года, поэтому версия 26.4.1 станет последним релизом вплоть второго квартала до 2028 года.
После возобновления разработки Vuzhyk перейдет с QT5 на собственную gui библиотеку, что значительно улучшит внешний вид при этом сохранив прежний уровень производительности на старых пк, а на новых но слабых производительность возможно даже вырастет.
Тогда же этот README будет хорошо оформлен и будет представлена gui библиотека "Relya"
Будет выпущена отдельная версия IDE не нацеленая на школы со значительно улучщеным агентом. А также поддеркой большего количества языков программирования.

IDE для Python (Qt 5.12, Windows 7+), школы Беларуси.


Сборка продукта: Visual Studio, `Vuzhyk.sln`, конфигурация **Release | x64**.
